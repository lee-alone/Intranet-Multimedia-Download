### 4. 认证处理器扩展

**文件**: [`internal/handler/auth.go`](../internal/handler/auth.go)

**新增处理器**:
- `HandleSSOLogin` - 处理 SSO 登录请求
- `GetSSOStatus` - 获取 SSO 服务状态
- `GetSSOLoginURL` - 获取 SSO 登录 URL
- `GetAgreementStatus` - 获取协议状态
- `AgreeToAgreement` - 同意协议
- `GetAgreementText` - 获取协议文本

**SSO 登录流程**:
1. 前端请求 SSO 登录 URL
2. 用户跳转到 SSO 服务商（CAS/OAuth2）
3. SSO 服务商回调，携带 ticket/code
4. 后端验证 ticket/code，获取用户信息
5. 查找或创建本地用户
6. 检查协议同意状态
7. 生成 JWT Token
8. 返回登录结果

## 📊 降级策略说明

### 降级机制

1. **触发条件**:
   - CAS/OAuth2 服务连接超时
   - CAS/OAuth2 服务返回错误
   - 网络异常

2. **降级行为**:
   - 设置 `degraded = true`
   - 记录 `degradedAt` 时间
   - 返回 "SSO service temporarily unavailable" 错误

3. **自动恢复**:
   - 降级超时默认 5 分钟
   - 超时后自动尝试恢复
   - 恢复成功后清除降级标记

### 降级状态转换

```
正常状态 ──(SSO 失败)──> 降级状态 ──(超时后尝试)──> 正常状态
     ↑                                              │
     └──────────────(恢复成功)──────────────────────┘
```
