## ✅ 完成的任务

### 1. JWT 密钥对生成工具（RS256）

**文件**: [`cmd/keygen/main.go`](cmd/keygen/main.go)

**功能说明**:
- 生成 RS256 算法的 RSA 密钥对
- 支持自定义密钥大小（最小 2048 位）
- 支持自定义输出目录
- 自动设置安全的文件权限（私钥 0600，公钥 0644）
- 输出 PEM 格式的密钥文件

**使用方法**:
```bash
# 使用默认设置生成密钥对
go run ./cmd/keygen

# 指定输出目录
go run ./cmd/keygen -o /etc/app/keys

# 生成 4096 位密钥对
go run ./cmd/keygen -s 4096

# 组合使用
go run ./cmd/keygen -o ./keys -s 4096
```

**命令行参数**:
| 参数 | 说明 | 默认值 |
|------|------|--------|
| `-o, --output` | 输出目录 | `./keys` |
| `-s, --size` | 密钥大小（位） | `2048` |
| `-h, --help` | 显示帮助信息 | - |

### 3. JWT Token 签发与验证

**文件**: [`internal/auth/auth.go`](internal/auth/auth.go)

### 5. LDAP 客户端对接

**文件**: [`internal/auth/ldap.go`](internal/auth/ldap.go)

**功能说明**:
- `LDAPClient` 结构体封装 LDAP 连接和认证
- `Authenticate()` 方法进行用户认证
- `TestConnection()` 方法测试 LDAP 连接
- 支持 LDAP over TLS (LDAPS)
- 支持连接超时设置

**LDAP 配置**:
```yaml
auth:
  ldap:
    enabled: false
    url: "ldap://ldap.example.com:389"
    bind_dn: "cn=admin,dc=example,dc=com"
    password: "${LDAP_PASSWORD:-}"
    base_dn: "ou=users,dc=example,dc=com"
    timeout: 10
```

**认证流程**:
1. 使用管理员账号绑定 LDAP 服务器
2. 搜索用户 DN
3. 使用用户凭据绑定验证密码
4. 认证成功后提取用户信息（uid, cn, mail）

**降级策略**:
- LDAP 认证失败时，可选择降级到本地认证
- 通过 `LDAPAuthHandler.AuthenticateWithFallback()` 实现

### 6. Refresh Token 持久化存储

**文件**: [`internal/auth/token_store.go`](internal/auth/token_store.go)

**功能说明**:
- `TokenStore` 结构体管理 Refresh Token 持久化
- `StoreRefreshToken()` 存储刷新令牌（SHA-256 哈希）
- `ValidateRefreshToken()` 验证刷新令牌是否有效
- `RevokeRefreshToken()` 撤销单个刷新令牌
- `RevokeAllUserTokens()` 撤销用户所有令牌
- `CleanupExpiredTokens()` 清理过期令牌

**安全特性**:
- 令牌存储前进行 SHA-256 哈希处理
- 支持令牌过期验证
- 支持令牌撤销（用于登出）

## ⚠️ 注意事项

1. **密钥安全**:
   - 私钥文件权限应为 0600（仅所有者可读写）
   - 私钥文件不应提交到版本控制系统
   - 生产环境建议使用 4096 位密钥

2. **LDAP 配置**:
   - 确保 LDAP 服务器可访问
   - 配置正确的 Base DN 和 Bind DN
   - 建议使用 LDAPS（ldap://）加密连接

3. **Token 安全**:
   - 访问令牌有效期建议设置为 15-60 分钟
   - 刷新令牌有效期建议设置为 24 小时
   - 客户端应安全存储令牌

4. **LDAP 用户密码**:
   - LDAP 用户的密码字段存储为特殊标记 `$ldap$only$`
   - 防止 LDAP 用户通过本地认证登录
