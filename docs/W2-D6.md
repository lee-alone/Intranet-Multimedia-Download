## 🔧 审核反馈修复

### 修复内容

#### 1. 下载失败时状态恢复问题
**问题**: 下载失败时 `e.status` 未设置为 `EngineStatusError`

**修复前**:
```go
if err != nil {
    result = DownloadResult{Success: false, Error: ...}
}
e.status = EngineStatusIdle  // 始终设置为 Idle
```

**修复后**:
```go
if err != nil {
    result = DownloadResult{Success: false, Error: ...}
    e.status = EngineStatusError  // 失败时设置为 Error
    e.lastError = result.Error
} else {
    e.status = EngineStatusIdle
}
```

**影响文件**:
- `internal/engine/ytdlp_engine.go`
- `internal/engine/lux_engine.go`

#### 2. Lux 引擎 `CanHandle` 逻辑改进
**问题**: 未匹配到域名时直接返回 `false`，与 yt-dlp 逻辑不一致

**修复前**:
```go
return false  // 未匹配到域名时返回 false
```

**修复后**:
```go
// 检查是否是有效的 HTTP(S) URL，让 lux 尝试处理未知网站
return strings.HasPrefix(urlLower, "http://") || strings.HasPrefix(urlLower, "https://")
```

#### 3. 进度解析正则表达式优化
**问题**: 原正则只能匹配 `[download]` 前缀格式

**修复前**:
```go
percentRe := regexp.MustCompile(`\[download\]\s+(\d+\.?\d*)%`)
```

**修复后**:
```go
percentRe := regexp.MustCompile(`(?:\[download\]\s*)?(\d+\.?\d*)%`)
```

支持格式：
- `[download] 50.0% of 10.00MiB`
- `50.0% of 10.00MiB` (无前缀)
- `[download] 100% of 10.00MiB at 1.50MiB/s ETA 0:00:10`

#### 4. 测试用例增强

- `TestLuxEngine_Download` - 测试 lux 下载流程

## ✅ 完成内容

### 1. 定义统一 Engine 接口

**文件**: [`internal/engine/engine.go`](internal/engine/engine.go)

实现了下载引擎的统一接口和核心组件：

```go
// Engine 是下载引擎的统一接口
type Engine interface {
    Name() string                              // 返回引擎名称
    Status() EngineStatus                      // 返回引擎状态
    CanHandle(url string) bool                 // 判断是否可以处理给定的 URL
    Download(ctx context.Context, url string, options DownloadOptions) <-chan DownloadProgress
    GetVersion() (string, error)               // 获取引擎版本
    IsAvailable() bool                         // 检查引擎是否可用
}
```

**核心功能**:
- `EngineStatus` - 引擎状态枚举（idle/running/error）
- `DownloadProgress` - 下载进度结构体
- `DownloadResult` - 下载结果结构体
- `DownloadOptions` - 下载配置选项
- `EngineSelector` - 引擎选择器，支持多引擎注册和自动选择
- 辅助函数：`buildOutputPath()`, `parseDuration()`

### 2. yt-dlp 引擎实现

**文件**: [`internal/engine/ytdlp_engine.go`](internal/engine/ytdlp_engine.go)

实现了 yt-dlp 下载引擎的完整封装：

**核心功能**:
- `YtdlpEngine` 结构体实现 `Engine` 接口
- `CanHandle()` - 支持主流视频网站（YouTube、Bilibili、优酷、腾讯等）
- `Download()` - 执行下载，通过 channel 实时推送进度
- `parseProgress()` - 解析 yt-dlp 命令行输出，提取进度、速度、ETA 等信息
- `GetVideoInfo()` - 获取视频详细信息（标题、时长、格式等）
- 支持配置：输出目录、画质选择、超时、Cookie、User-Agent、代理

**支持的网站**:
- YouTube, Bilibili, 优酷，腾讯视频，爱奇艺
- 芒果 TV，搜狐视频，AcFun，抖音，TikTok
- Twitter/X, Facebook, Instagram, Vimeo 等

### 4. 引擎选择逻辑

**EngineSelector** 提供智能引擎选择：

```go
selector := NewEngineSelector(EngineTypeAuto)
selector.AddEngine(NewYtdlpEngine(YtdlpConfig{}))
selector.AddEngine(NewLuxEngine(LuxConfig{}))

// 根据 URL 自动选择最合适的引擎
engine := selector.Select(url)
```

**选择策略**:
1. 遍历已注册的引擎
2. 调用 `CanHandle()` 判断是否支持
3. 返回第一个支持的引擎
4. 如都不支持，返回 nil
