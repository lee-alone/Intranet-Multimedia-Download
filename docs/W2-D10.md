- 线程安全（使用 `sync.RWMutex`）

**代码示例**:
```go
// 创建白名单管理器
whitelistMgr := middleware.NewWhitelistManager(cfg.Download.Whitelist)

// 标准化域名处理
func normalizeDomain(domain string) string {
    domain = strings.TrimSpace(domain)
    domain = strings.ToLower(domain)
    domain = strings.TrimPrefix(domain, "www.")
    domain = strings.Trim(domain, ".")
    return domain
}
```

### 2. URL 校验中间件

**实现位置**: [`internal/middleware/whitelist.go`](internal/middleware/whitelist.go)

**核心函数**:
```go
// 从 URL 中提取域名
func ExtractDomain(rawURL string) (string, error)

// 验证 URL 是否在白名单中
func ValidateURL(wm *WhitelistManager, rawURL string) error
```

**校验流程**:
1. 从 URL 中提取域名（支持 `http://`、`https://` 或无协议前缀）
2. 标准化域名（去 `www.`、转小写）
3. 查询白名单
4. 不在白名单则返回 `URLValidationError` 错误

**集成到 TaskHandler**:
```go
// 在 CreateBatchTask 中校验每个 URL
for _, rawURL := range req.URLs {
    // 白名单校验
    if h.whitelistMgr != nil {
        if err := middleware.ValidateURL(h.whitelistMgr, rawURL); err != nil {
            if urlErr, ok := err.(*middleware.URLValidationError); ok {
                if urlErr.Code == "E401" {
                    writeError(w, http.StatusForbidden, "该网站不在允许下载范围内")
                    return
                }
            }
        }
    }
}
```

## 🔧 技术要点

### 1. 线程安全的白名单管理

使用 `sync.RWMutex` 实现读写锁：
```go
type WhitelistManager struct {
    mu        sync.RWMutex
    whitelist map[string]bool
}

// 读操作使用 RLock
func (wm *WhitelistManager) IsAllowed(domain string) bool {
    wm.mu.RLock()
    defer wm.mu.RUnlock()
    // ...
}

// 写操作使用 Lock
func (wm *WhitelistManager) AddDomain(domain string) {
    wm.mu.Lock()
    defer wm.mu.Unlock()
    // ...
}
```

### 2. 域名标准化

统一处理域名格式，避免重复：
- 去除前后空格
- 转小写
- 去除 `www.` 前缀
- 去除前后点号

### 3. URL 域名提取

使用 `net/url` 包解析 URL：
```go
func ExtractDomain(rawURL string) (string, error) {
    if !strings.HasPrefix(rawURL, "http://") && !strings.HasPrefix(rawURL, "https://") {
        rawURL = "https://" + rawURL
    }
    u, err := url.Parse(rawURL)
    if err != nil {
        return "", err
    }
    return u.Hostname(), nil
}
```

### 4. 错误处理

使用自定义错误类型，支持错误码和详细信息：
```go
type URLValidationError struct {
    Code    string `json:"code"`
    Message string `json:"message"`
    URL     string `json:"url,omitempty"`
    Domain  string `json:"domain,omitempty"`
    Err     error  `json:"-"`
}
```
