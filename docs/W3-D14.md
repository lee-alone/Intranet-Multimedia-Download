### 3. 断点续传支持

**实现原理**:
- 客户端发送 `Range: bytes=start-end` 请求头
- 服务端解析 Range 并返回 `206 Partial Content`
- 使用 `Content-Range` 响应头标明实际传输范围
- 使用 `Accept-Ranges: bytes` 表明支持范围请求
