### 5. 路由与权限控制

**文件**: [`web/src/router/index.ts`](../web/src/router/index.ts)

**权限控制逻辑**:
```
┌─────────────────────────────────────┐
│         路由守卫 (beforeEach)        │
└─────────────────────────────────────┘
                 │
    ┌────────────┴────────────┐
    │                         │
    ▼                         ▼
requiresAuth?           requiresGuest?
    │                         │
    ├─ Yes ─┐                ├─ Yes ─┐
    │       │                │       │
    ▼       ▼                ▼       ▼
有 token?  跳转登录        有 token?  跳转首页
    │
    ├─ No ─► 跳转登录
    │
    └─ Yes ─► 放行
```

**改进点**:
- 使用 `defineAsyncComponent` 进行组件懒加载
- 添加类型安全的元信息接口
- 页面标题自动设置
- 路由切换时滚动到顶部

### 6. API 层改进

**文件**: [`web/src/api/index.ts`](../web/src/api/index.ts)

**主要改进**:
- 更新 `ApiResponse` 类型定义，与后端 API 规范一致
- 添加 WebSocket 认证工具函数 `createWebSocketUrl()`
- 添加 `createAuthenticatedWebSocket()` 方法
- 请求拦截器优先从 sessionStorage 获取 token

**API 响应类型**:
```typescript
export interface ApiResponse<T = unknown> {
  code: number      // 错误码：0 表示成功
  message: string   // 消息
  data?: T          // 数据
}
```
