### 1. 数据库表结构

审计日志表 `audit_logs` 已在初始迁移文件 [`migrations/20260325100000_init.sql`](migrations/20260325100000_init.sql:50) 中定义：

```sql
CREATE TABLE IF NOT EXISTS audit_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,
    action TEXT NOT NULL,
    resource_type TEXT,
    resource_id INTEGER,
    ip_address TEXT,
    user_agent TEXT,
    detail TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

表结构包含以下字段：
- `id`: 主键
- `user_id`: 关联用户 ID
- `action`: 操作类型（login、logout、register、create_task 等）
- `resource_type`: 资源类型（user、task、batch_task）
- `resource_id`: 资源 ID
- `ip_address`: 客户端 IP 地址
- `user_agent`: 用户代理字符串
- `detail`: 详细信息（JSON 格式）
- `created_at`: 创建时间

### 2. 审计日志模块实现

创建了 [`internal/audit/`](internal/audit/) 包，包含以下核心功能：

#### 2.1 日志记录器 ([`audit.go`](internal/audit/audit.go))

**主要类型和接口：**

- `ActionType`: 定义审计日志的操作类型
  - `ActionLogin`: 用户登录
  - `ActionLogout`: 用户登出
  - `ActionRegister`: 用户注册
  - `ActionCreateTask`: 创建任务
  - `ActionDeleteTask`: 删除任务
  - `ActionCancelTask`: 取消任务
  - `ActionDownload`: 下载文件
  - `ActionViewAudit`: 查看审计日志
  - `ActionMFAEnable`: 启用 MFA
  - `ActionMFADisable`: 禁用 MFA

- `ResourceType`: 定义资源类型
  - `ResourceTypeUser`: 用户资源
  - `ResourceTypeTask`: 任务资源
  - `ResourceTypeBatchTask`: 批量任务资源

- `AuditLog`: 审计日志记录结构体
- `Logger`: 审计日志记录器
- `FileLogger`: 文件日志记录器

**核心功能：**

1. **日志写入接口** ([`Logger.Log()`](internal/audit/audit.go:192))
   - 支持数据库和文件双写
   - 自动脱敏处理
   - 线程安全（使用互斥锁）

2. **URL 脱敏规则** ([`sanitizeURL()`](internal/audit/audit.go:296))
   - 自动识别 URL 中的敏感参数
   - 敏感参数包括：password、token、api_key、access_token、refresh_token、authorization、auth、credential、credentials
   - 将敏感值替换为 `***`

3. **日志轮转策略** ([`FileLogger.rotate()`](internal/audit/audit.go:127))
   - 按日期自动轮转
   - 文件命名格式：`audit_YYYY-MM-DD.log`
   - 自动检测日期变更并创建新文件

4. **日志查询接口** ([`Logger.Query()`](internal/audit/audit.go:337))
   - 支持按用户 ID、操作类型、资源类型过滤
   - 支持分页查询（limit、offset）
   - 按创建时间倒序排列

#### 问题 2：Handler 未使用审计日志模块

**问题描述**：`internal/handler/auth.go` 中的 `auditLog()` 方法直接使用 SQL 插入，未使用新的 `audit.Logger`

**修复内容**：
- 在 `AuthHandler` 结构体中添加 `auditLogger *audit.Logger` 字段
- 更新 `NewAuthHandler()` 函数签名，增加 `auditLogger` 参数
- 重写 `auditLog()` 方法，使用 `audit.Logger.Log()` 接口
- 添加辅助函数 `int64Ptr()` 和 `resourceTypePtr()`

**修改文件**：[`internal/handler/auth.go`](internal/handler/auth.go)

```go
// auditLog 记录审计日志
func (h *AuthHandler) auditLog(r *http.Request, userID int, action, resourceType string, resourceID int, detail string) {
    ip := getClientIP(r)
    
    auditLog := &audit.AuditLog{
        UserID:       int64Ptr(userID),
        Action:       audit.ActionType(action),
        ResourceType: resourceTypePtr(audit.ResourceType(resourceType)),
        ResourceID:   int64Ptr(resourceID),
        IPAddress:    ip,
        UserAgent:    r.UserAgent(),
        Detail:       map[string]interface{}{"detail": detail},
    }
    
    if err := h.auditLogger.Log(auditLog); err != nil {
        log.Printf("Failed to write audit log: %v", err)
    }
}
```
