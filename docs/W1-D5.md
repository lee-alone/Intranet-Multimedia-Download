## 完成情况

### 1. 健康检查端点增强

在原有基础上增强了健康检查功能，实现了多个检查端点：

| 端点 | 功能 | 返回格式 | HTTP 状态 |
|------|------|----------|-----------|
| `/health` | 简化健康检查 | JSON | 200/503 |
| `/healthz` | 详细健康检查 | JSON | 200/503 |
| `/ready` | 就绪检查 | JSON | 200/503 |
| `/live` | 存活检查 | JSON | 200 |
| `/metrics` | Prometheus 指标 | Prometheus 格式 | 200 |
| `/api/v1/metrics` | API 指标 | JSON | 200 |

### 2. 依赖项检测功能

实现了自动检测外部依赖项的功能：

**检测项目：**
- **yt-dlp**: 视频下载引擎
- **ffmpeg**: 音视频处理工具
- **数据库**: SQLite 连接状态

**检测结果示例：**
```json
{
  "status": "healthy",
  "timestamp": "2026-03-26T13:32:32+08:00",
  "database": true,
  "yt_dlp": {
    "name": "yt-dlp",
    "available": true,
    "version": "2025.12.08"
  },
  "ffmpeg": {
    "name": "ffmpeg",
    "available": false,
    "error": "exec: \"ffmpeg\": executable file not found in %PATH%"
  }
}
```

### 3. Prometheus 指标暴露

实现了标准的 Prometheus 格式指标输出：

```
# HELP server_health 服务器健康状态 (1=healthy, 0=unhealthy)
# TYPE server_health gauge
server_health 1

# HELP server_database_health 数据库健康状态
# TYPE server_database_health gauge
server_database_health 1

# HELP server_ytdlp_available yt-dlp 是否可用
# TYPE server_ytdlp_available gauge
server_ytdlp_available 1

# HELP server_ffmpeg_available ffmpeg 是否可用
# TYPE server_ffmpeg_available gauge
server_ffmpeg_available 0

# HELP server_uptime_seconds 服务器运行时间（秒）
# TYPE server_uptime_seconds counter
server_uptime_seconds 9223372037
```

### 4. 健康状态机

实现了三种健康状态：
- **healthy**: 数据库正常且至少一个下载引擎可用
- **degraded**: 数据库正常但所有下载引擎不可用
- **unhealthy**: 数据库连接失败

## 技术亮点

1. **线程安全设计**
   - 使用 `sync.RWMutex` 保护健康状态
   - 读多写少场景优化
   - 并发测试验证

2. **优雅降级**
   - 支持三种健康状态
   - 降级状态仍返回可用响应
   - 明确的状态转换逻辑

3. **标准化指标**
   - Prometheus 格式兼容
   - 支持 Grafana 等监控系统
   - 标准的 HELP 和 TYPE 注释

4. **详细错误信息**
   - 依赖项缺失时提供具体错误
   - 便于问题排查
   - 版本信息自动采集
