## 🔧 代码修复与改进

在性能测试过程中，发现并修复了以下问题：

### 1. 任务状态转换 Bug

**问题**: `executeTask` 函数中尝试从 `TaskStatusDownloading` 直接转换到 `TaskStatusCompleted`，但根据 `ValidTransitions` 定义，这是不允许的。

**修复方案**: 修改 `internal/engine/scheduler.go`，先转换到 `TaskStatusMerging`，然后再转换到 `TaskStatusCompleted`。

**修改内容**:
```go
// 修复前
task.TransitionStatus(TaskStatusCompleted)

// 修复后
task.TransitionStatus(TaskStatusMerging)
task.TransitionStatus(TaskStatusCompleted)
```

### 2. 信号量未释放 Bug

**问题**: `consumerLoop` 中获取信号量后，`executeTask` 函数完成后未释放信号量，导致后续任务无法执行。

**修复方案**: 在 `executeTask` 函数开始处添加 `defer func() { <-s.semaphore }()` 释放信号量。

**修改内容**:
```go
func (s *TaskScheduler) executeTask(task *Task) {
	defer func() { <-s.semaphore }() // 释放信号量
	// ... 其余逻辑
}
```
