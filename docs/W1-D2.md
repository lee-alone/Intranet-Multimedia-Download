### 问题1: Windows 平台文件权限检查失效风险 ✅ 已修复

**问题描述**: Windows 不支持 Unix 权限位，`0077` 掩码在 Windows 上行为不确定。

**修复方案**: 添加平台检测，Windows 上使用简化的安全检查。

**修复文件**: [`internal/config/config.go`](internal/config/config.go:226)

```go
// checkFilePermissions 检查配置文件权限是否安全
func checkFilePermissions(path string) error {
    // Windows 平台不支持 Unix 权限位检查
    if isWindows() {
        // Windows 平台：简化检查，生产环境建议使用 ACL API
        return nil
    }
    // Unix/Linux 平台：检查文件权限
    mode := info.Mode()
    if mode&0077 != 0 {
        return fmt.Errorf("config file %s has insecure permissions: %v", path, mode)
    }
    return nil
}

// isWindows 检测当前操作系统是否为 Windows
func isWindows() bool {
    return os.PathSeparator == '\\' && os.PathListSeparator == ';'
}
```

### 问题4: 数据库连接池配置可能不合理 ✅ 已修复

**问题描述**: 当 `MaxConns=1` 时，`MaxIdleConns=0`，可能导致连接频繁创建销毁。

**修复方案**: 添加最小值保护：`max(1, cfg.MaxConns/2)`。

**修复文件**: [`internal/database/database.go`](internal/database/database.go:49)

```go
// 设置连接池
db.SetMaxOpenConns(cfg.MaxConns)
// 确保 MaxIdleConns 至少为 1，避免连接频繁创建销毁
maxIdleConns := cfg.MaxConns / 2
if maxIdleConns < 1 {
    maxIdleConns = 1
}
db.SetMaxIdleConns(maxIdleConns)
```

```go
// checkFilePermissions 检查配置文件权限是否安全
func checkFilePermissions(path string) error {
    info, err := os.Stat(path)
    if err != nil {
        return err
    }
    // 检查文件权限（不应被其他用户可写）
    mode := info.Mode()
    if mode&0077 != 0 {
        return fmt.Errorf("config file %s has insecure permissions: %v", path, mode)
    }
    return nil
}
```

**安全检查**:
- 配置文件不应被其他用户可写
- 权限应为 0600 或 0640 等安全权限
- 权限异常时程序拒绝启动
