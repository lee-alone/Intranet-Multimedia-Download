## Go 环境安装

### Windows 系统

#### 步骤 1：下载 Go 安装包

1. 访问 Go 官网下载页面：https://go.dev/dl/
2. 下载最新稳定版（推荐 1.25+）
3. 选择 `go1.25.x.windows-amd64.msi` 安装包

#### 步骤 2：安装 Go

1. 双击运行下载的 `.msi` 安装包
2. 按照安装向导完成安装
3. 默认安装路径：`C:\Program Files\Go\`
4. 安装程序会自动配置环境变量

#### 步骤 3：验证安装

打开命令提示符（cmd）或 PowerShell，执行：

```cmd
go version
```

预期输出：
```
go version go1.25.4 windows/amd64
```

#### 步骤 4：配置环境变量（如需要）

如果 `go` 命令不可用，手动添加环境变量：

1. 右键"此电脑" → "属性" → "高级系统设置"
2. 点击"环境变量"
3. 在"系统变量"中找到 `Path`
4. 添加 `C:\Program Files\Go\bin`
5. 新建系统变量：
   - 变量名：`GOPATH`
   - 变量值：`C:\Users\你的用户名\go`

---

### Linux 系统（Ubuntu/Debian）

#### 步骤 1：下载 Go

```bash
# 下载 Go 1.25.4
wget https://go.dev/dl/go1.25.4.linux-amd64.tar.gz
```

#### 步骤 2：解压到安装目录

```bash
# 解压到 /usr/local
sudo tar -C /usr/local -xzf go1.25.4.linux-amd64.tar.gz
```

#### 步骤 3：配置环境变量

编辑 `~/.profile` 或 `~/.bashrc`：

```bash
nano ~/.profile
```

添加以下内容：

```bash
export PATH=$PATH:/usr/local/go/bin
export GOPATH=$HOME/go
export PATH=$PATH:$GOPATH/bin
```

使配置生效：

```bash
source ~/.profile
```

#### 步骤 4：验证安装

```bash
go version
```

预期输出：
```
go version go1.25.4 linux/amd64
```

---

## CGO 编译环境

项目使用 `go-sqlite3` 驱动，需要 CGO 支持。如需使用 CGO 模式编译（获得更好的 SQLite 性能），需要安装 C 编译器。

### Windows - 安装 MinGW-w64

#### 步骤 1：下载

访问：https://www.mingw-w64.org/downloads/

或使用 winget 安装 MSYS2：

```powershell
winget install MSYS2.MSYS2
```

#### 步骤 2：安装

```powershell
# 使用 MSYS2 安装 GCC
pacman -S mingw-w64-x86_64-gcc
```

#### 步骤 3：配置环境变量

将 MinGW 的 bin 目录添加到 PATH：
- `C:\msys64\mingw64\bin`

#### 步骤 4：验证

```cmd
gcc --version
```

#### Ubuntu/Debian

```bash
sudo apt-get update
sudo apt-get install build-essential

```

#### CentOS/RHEL

```bash
sudo yum groupinstall "Development Tools"
sudo yum install gcc gcc-c++ make
```

### macOS - 安装 Xcode Command Line Tools

## 项目编译

### 1. 克隆项目

```bash
git clone https://github.com/campus/collector.git
cd Intranet-Multimedia-Download
```

### 2. 安装 Go 依赖

```bash
go mod download
```

### 3. 安装前端依赖

```bash
cd web
npm install
cd ..
```

### 4. 构建前端资源

```bash
cd web
npm run build
cd ..
```

构建完成后，前端资源将输出到 `web/dist/` 目录。

### 5. 编译后端

#### 纯 Go 模式（推荐，无需 CGO）

**Windows:**

```cmd
set CGO_ENABLED=0
set GOOS=windows
set GOARCH=amd64
go build -ldflags="-s -w" -o dist/collector.exe ./cmd/server
```

**Linux:**

```bash
export CGO_ENABLED=0
export GOOS=linux
export GOARCH=amd64
go build -ldflags="-s -w" -o dist/collector ./cmd/server
```

#### CGO 模式（需要 C 编译器）

**Windows:**

```cmd
set CGO_ENABLED=1
set GOOS=windows
set GOARCH=amd64
go build -ldflags="-s -w" -o dist/collector.exe ./cmd/server
```

**Linux:**

```bash
export CGO_ENABLED=1
export GOOS=linux
export GOARCH=amd64
go build -ldflags="-s -w" -o dist/collector ./cmd/server
```

### 6. 编译密钥生成工具

```bash
go build -ldflags="-s -w" -o dist/keygen.exe ./cmd/keygen
```

## 部署步骤

### 1. 准备部署目录

```bash
# 创建部署目录结构
mkdir -p /opt/collector/{bin,runtime,logs,data,keys}
```

### 2. 复制编译产物

```bash
# 复制主程序
cp dist/collector /opt/collector/bin/

# 复制密钥生成工具
cp dist/keygen /opt/collector/bin/

# 复制外部依赖
cp runtime/yt-dlp /opt/collector/runtime/
cp runtime/ffmpeg /opt/collector/runtime/
```

### 3. 配置文件

```bash
# 复制配置示例
cp config.yaml.example /opt/collector/config.yaml

# 编辑配置
nano /opt/collector/config.yaml
```

### 4. 生成 JWT 密钥

```bash
cd /opt/collector
./bin/keygen -o ./keys -s 4096
```

### 5. 设置权限

```bash
# 设置目录权限
chmod 755 /opt/collector/bin
chmod 700 /opt/collector/keys
chmod 600 /opt/collector/keys/private.pem
chmod 644 /opt/collector/keys/public.pem

# 设置所有者（如使用专用用户）
chown -R collector:collector /opt/collector
```

### 6. 配置环境变量（可选）

创建 `/etc/systemd/system/collector.service`：

```ini
[Unit]
Description=Campus Collector Service
After=network.target

[Service]
Type=simple
User=collector
WorkingDirectory=/opt/collector
ExecStart=/opt/collector/bin/collector
Restart=on-failure
Environment="PATH=/usr/local/go/bin:/usr/bin:/bin"

[Install]
WantedBy=multi-user.target
```

### 7. 启动服务

```bash
# 启用并启动服务
sudo systemctl daemon-reload
sudo systemctl enable collector
sudo systemctl start collector

# 查看状态
sudo systemctl status collector
```

## 故障排查

### 问题 1：`go: command not found`

**原因：** Go 未安装或环境变量未配置

**解决：**
1. 确认 Go 已安装
2. 检查 PATH 环境变量是否包含 Go 的 bin 目录
3. 重启终端或执行 `source ~/.profile`

### 问题 2：`gcc: command not found`

**原因：** CGO 环境未安装

**解决：**
- Windows: 安装 MinGW-w64 或 TDM-GCC
- Linux: `sudo apt-get install build-essential`
- macOS: `xcode-select --install`

或使用纯 Go 模式编译：
```bash
export CGO_ENABLED=0
go build ...
```

### 问题 3：前端资源未嵌入

**原因：** 前端未构建或 embed 路径错误

**解决：**
1. 确认已执行 `npm run build`
2. 检查 `web/dist/` 目录是否存在
3. 检查 [`embed.go`](embed.go:1) 中的路径配置

### 问题 4：数据库锁定

**原因：** SQLite 文件被占用

**解决：**
1. 检查是否有其他进程占用数据库文件
2. 确认配置中 `database.wal_mode` 为 true
3. 检查文件权限

### 问题 5：yt-dlp 无法下载

**原因：** 依赖未安装或版本过旧

**解决：**
1. 确认 yt-dlp 已安装并可执行
2. 更新到最新版本
3. 检查域名白名单配置
